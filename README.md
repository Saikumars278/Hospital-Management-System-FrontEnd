# Hospital Management System

## Description

Hospital Management System is a full stack web application developed using React and Django.

---

## Features

- Patient Management
- Doctor Management
- Appointment Booking
- JWT Authentication
- Billing System

---

## Tech Stack

- React
- Django
- MySQL
- REST API
